# Character pack: ทำตัวละครของคุณเอง

น้องหมาใน IslandPup คือ "pack" ชุดหนึ่ง (โฟลเดอร์ของไฟล์ PNG) ถ้าทำโฟลเดอร์ในรูปแบบเดียวกัน จะเปลี่ยนเป็นแมว หุ่นยนต์ หรืออะไรก็ได้

> สถานะข้อมูล: ชื่อท่า จำนวนเฟรม และขนาดภาพมาจากการอ่าน `Sources/Vorssaint/UI/Notch/NotchDogSprite.swift` ส่วนตำแหน่งโฟลเดอร์และ field ของ `pack.json` เป็นงานของโค้ด pack ที่ยังไม่อยู่ใน branch นี้ จึงเขียนตามข้อตกลงของทีม ให้ตรวจกับ `NotchPackSupport.swift` เมื่อรวมโค้ดแล้ว (ดู TODO ท้ายไฟล์)

## ที่เก็บ pack

โฟลเดอร์ Application Support ของแอป ในโฟลเดอร์ย่อย `Pets`:

```
~/Library/Application Support/<ชื่อโฟลเดอร์ของแอป>/Pets/<packName>/
```

`<ชื่อโฟลเดอร์ของแอป>` คือค่าคงที่ `NotchPackSupport.appFolderName` ในโค้ด ถ้าหาไม่เจอ ให้เปิด Finder > Go > Go to Folder แล้วดูในโฟลเดอร์ `~/Library/Application Support/` ว่าแอปสร้างโฟลเดอร์ชื่ออะไรไว้ แล้วสร้าง `Pets` ในนั้นเอง

## ชื่อไฟล์

ทุกเฟรมเป็น PNG ชื่อ `<action>_<n>.png` โดย `n` นับจาก 0 เรียงต่อกันไม่ข้าม (ตัวโหลดของน้องหมาที่มากับแอปอ่าน 0 ถึง จำนวนเฟรม - 1 ถ้าขาดเฟรมใดเฟรมหนึ่ง ท่านั้นถือว่าโหลดไม่สำเร็จทั้งท่า)

จำนวนเฟรมและความเร็วเริ่มต้นของ pack น้องหมาที่มากับแอป:

| action | เฟรม | วินาทีต่อเฟรม | ใช้เมื่อ |
|---|---|---|---|
| `walk` | 8 | 0.11 | ท่าปกติ, CPU ต่ำ (ต้องมี) |
| `run` | 10 | 0.06 | CPU ปานกลาง |
| `sprint` | 8 | 0.04 | CPU สูง |
| `music` | 8 | 0.12 | กำลังเล่นเพลง |
| `lowbat` | 6 | 0.30 | แบตต่ำ |
| `charging` | 8 | 0.10 | กำลังชาร์จ |
| `hot` | 8 | 0.12 | เครื่องร้อน |
| `latenight` | 8 | 0.30 | ดึก (23:00 ถึง 04:59) |
| `wake` | 6 | 0.12 | เพิ่งตื่นหรือปลดล็อก |
| `sleep` | 6 | 0.35 | ไม่แตะเครื่องนาน |
| `awake` | 6 | 0.30 | ไม่แตะเครื่องแต่เปิด Keep Awake |
| `working` | 8 | 0.14 | มี Claude Code ทำงาน |
| `focus` | 6 | 0.30 | Timer กำลังเดิน |
| `meeting` | 6 | 0.25 | ไมโครโฟนถูกใช้ |
| `typing` | 8 | 0.08 | กำลังพิมพ์ |

pack ของคุณไม่จำเป็นต้องใช้จำนวนเฟรมเท่ากับตาราง แต่ตัวโหลดของน้องหมาที่มากับแอปคาดตามตารางนี้ ถ้าจะใช้จำนวนอื่น ให้ตรวจกับโค้ดโหลด pack (ดู TODO) หรือทำตามตารางไปก่อนเพื่อความปลอดภัย

ตัวอย่างชื่อไฟล์: `walk_0.png` ถึง `walk_7.png`, `sleep_0.png` ถึง `sleep_5.png`

## ขนาดและการวางตัวละคร

- ขนาดแนะนำ **144 x 128 px** พื้นหลังโปร่งใส (RGBA) เฟรมในน้องหมาที่มากับแอปเป็นขนาดนี้ทุกเฟรม
- ตัวละครหันไปทาง **ขวา**
- **เท้าอยู่ที่กึ่งกลางด้านล่าง** ของเฟรม และทุกเฟรมวางตัวละครไว้ตำแหน่งเดียวกัน ไม่งั้นตัวจะกระตุกเวลาเล่นภาพต่อกัน
- ภาพถูกย่อลงเหลือประมาณความสูงของแถบ Island และวาดแบบ nearest neighbour (ไม่เกลี่ยขอบ) pixel art จึงยังคมอยู่ ภาพที่ไม่ใช่ pixel art ก็ใช้ได้แต่จะดูหยาบ
- ไว้ขอบว่างเล็กน้อยรอบตัว เพื่อไม่ให้ตัวโดนตัดตอนย่อ

## pack.json

ไฟล์ `pack.json` อยู่ในโฟลเดอร์เดียวกับรูป ตัวอย่างสมบูรณ์:

```json
{
  "name": "Mochi the Cat",
  "facing": "right",
  "intervals": {
    "walk": 0.11,
    "run": 0.06,
    "sprint": 0.04,
    "music": 0.12,
    "sleep": 0.35,
    "typing": 0.08
  }
}
```

| field | ความหมาย |
|---|---|
| `name` | ชื่อที่แสดงในรายการเลือก |
| `facing` | ทิศที่ตัวละครหันในรูป `"right"` (ค่าแนะนำ) หรือ `"left"` ถ้าวาดหันซ้าย |
| `intervals` | วินาทีต่อเฟรมของแต่ละท่า ใส่เฉพาะท่าที่ต้องการเปลี่ยน ท่าที่ไม่ใส่ใช้ค่าเริ่มต้นในตารางข้างบน |

## กติกา

- **`walk_0.png` จำเป็น** ถ้าไม่มี pack ใช้ไม่ได้
- ท่าที่ไม่มี (หรือมีไม่ครบเฟรม) จะ **ถอยกลับไปใช้ท่า `walk`** (พฤติกรรมนี้อยู่ใน `NotchDogSprite.swift` ของน้องหมาเดิม) ทำแค่ `walk` อย่างเดียวก็ใช้ได้ แล้วค่อยเพิ่มท่าทีละท่า
- แก้ไฟล์แล้วภาพยังไม่เปลี่ยน ให้ลองเลือก pack ใหม่หรือปิดเปิดแอป (น้องหมาที่มากับแอปโหลดภาพครั้งเดียวต่อรอบการเปิดแอป ไม่ได้ตรวจว่า pack ทำเหมือนกันหรือไม่)

## เลือก pack ใน Settings

Settings > **Dynamic Island** > แท็บ **Companion** > **Appearance** > **Style** ถ้า build ของคุณรองรับ pack ชื่อใน `name` จะอยู่ในรายการสไตล์ ถ้าไม่เห็น ให้ตรวจชื่อโฟลเดอร์ ตำแหน่งโฟลเดอร์ และว่ามี `walk_0.png`

## ทำภาพด้วย image AI (ขั้นตอนทั่วไป)

เอกสารนี้ไม่ระบุชื่อเครื่องมือ ใช้ image generator ตัวไหนก็ได้ที่คุมสไตล์ได้

1. เขียน prompt อธิบายตัวละคร สไตล์ (เช่น pixel art, ตัวละครเดียว, หันขวา) และท่าที่ต้องการ ให้ **ตัวละครหน้าตาเดิมทุกท่า** โดยแนบรูปอ้างอิงตัวแรกทุกครั้งถ้าเครื่องมือรองรับ
2. ขอให้วาดเป็น **sprite sheet** ท่าละแถว วางบน **พื้นหลังสีเดียวล้วน สีม่วงแดง magenta (#FF00FF)** เพราะแยกออกจากตัวละครง่าย และไม่ค่อยซ้ำกับสีในตัวละคร
3. ตรวจจำนวนเฟรมในแต่ละแถว image AI มักนับเฟรมผิด ถ้าไม่ตรง ให้ gen ซ้ำหรือตัดเฟรมที่เกินทิ้ง
4. ตัด sheet เป็นเฟรมทีละช่อง (ด้วยสคริปต์ที่แบ่งตามตาราง หรือโปรแกรมแต่งภาพก็ได้) ปรับทุกเฟรมให้อยู่ในผืน 144 x 128 โดยเท้าอยู่ตำแหน่งเดียวกัน
5. ลบสี magenta ให้เป็นพื้นหลังโปร่งใส ระวังขอบที่ยังมีสีม่วงแดงติด (fringe) ถ้าเห็น ให้เก็บขอบหรือขยับ threshold
6. ตั้งชื่อไฟล์ตามรูปแบบ `<action>_<n>.png` ใส่ในโฟลเดอร์ pack พร้อม `pack.json`
7. เปิดแอปแล้วใช้ท่าจริง (เช่นเริ่ม Timer เพื่อดู `focus`) ดูว่าภาพไม่กระตุกและเท้าไม่ลอย
